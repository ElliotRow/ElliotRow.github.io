Internet Application and Database Design (Year 1)

HTML5 | CSS | JavaScript | PHP | SQL

Created a website to support the creation, detailing and managing of the progress of multiple projects.

E-Commerce Web Application (Year 2)

HTML5 | CSS | JavaScript | MongoDB | JSON

Worked as part of a team of four, to collaboratively design and develop a faux online jewellery shopping platform, that allowed users to set up an account to browse and keep track of all their product purchases.

• MongoDB was selected and installed as our database software, used to store both customer information and project data, as the team felt this was the best option to support the website's functionality.

Game Development Project (Year 3)

Unity | C# | JSON

Created a functional demo of a factory style cooking game, incorporating custom 3D and 2D assets. This game involved managing the needs of a restaurant, while serving as both the chef and server through automating the various processes involved.

• Created a comprehensive game design document to outline the key features of the design, such as the gameplay loop, win conditions and fail states, along with outlining how the gameplay meets the design considerations outlined in the brief.

• Developed using a unity engine and assets were created through clip studio and blender as I felt using unity store assets was too impersonal for my design considerations.

• Incorporated a working gameplay loop and the ability to save and load progress across sessions.

• The build required in-depth testing to find and fix bugs encountered during the project development.

Animation Project (Year 3)

Blender

Used Blender to create a bespoke 2-minute-long animation, incorporating all of the skills taught throughout the animation unit along with my own extracurricular research and practice to create an animation about a prisoner trapped beneath a mountain.

• Used shader nodes to create advanced materials such as realistic brick and concrete, along with Compositing to create bloom effects for more customised lighting.

• Utilised sculpting on certain objects such as the heart and lungs to make the design look more true to life, along with keyframing to make them perform their functions.

• Used constraints on the camera to better control its movements while not having it “stutter” as it would with simple keyframe based movement.

The animation can be found in the 3D Portfolio
